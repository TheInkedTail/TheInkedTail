Save & Load

The sheet you're on autosaves in this browser as you type. Use these to keep a copy somewhere safer, move it to another device, or juggle more than one character.

As a file

Saves a small .json file. Open it here later, on any device, to pick up where you left off. Sheets saved as .html from the older version open too. You can also drop a file anywhere on the page.

Characters in this browser

When you open or start another character, the one you were on is kept here, so you can switch back. These live only in this browser; clearing site data removes them.

As text

If file saving doesn't work where you are, copy this text and keep it somewhere (a note, an email to yourself). Paste it back here and press Load to restore the character.
